# 0005. 팀 저장소의 공유 자산은 제안만 한다

- 상태: 승인 (2026-09-22)

## 맥락

혼자 쓰는 저장소와 팀 저장소는 고쳐도 되는 것이 다르다. 팀 저장소에서 `repo-secure` 와
`repo-contrib` 은 대부분 권한이 없어 실패한다. 그 실패를 결함으로 보고하면 권한이 없는 것이 정상인
상황을 오류로 읽게 된다.

## 결정

팀 저장소면 공유 자산을 고치지 않고 제안만 한다. 권한이 없어 실패한 것은 결함으로 보고하지 않고
「권한이 없어 제안만 한다」로 처리한다.

## 결과

- 팀 저장소에서 세팅이 팀의 합의 없이 들어가지 않는다.
- 팀 저장소에서는 무엇을 하면 좋을지가 보고로만 남고, 적용은 사람이 팀과 합의해서 한다.
- 어떤 단계가 공유 자산을 건드리는지는 목적마다 다르므로 각 스킬 본문의 「팀 저장소일 때」 절이 정한다.
