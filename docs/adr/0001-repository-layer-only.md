# 0001. 저장소 층만 다룬다

- 상태: 승인 (2026-09-22)

## 맥락

저장소를 세팅할 때 손댈 수 있는 것은 두 층이다. 하나는 git 과 GitHub 에 속하는 것이고, 다른 하나는
린터, 포매터, 테스트 러너, 빌드 설정 같은 언어별 도구 체인이다.

- 저장소 층은 파일을 놓았는지, 훅이 실제로 막는지, GitHub API 가 무엇을 돌려주는지로 전부 판정된다.
  언어가 섞이면 스킬마다 검증 수단이 달라지고, 검증할 수 없는 스킬이 생긴다.
- 도구 체인은 이미 `npm create`, `uv init`, 프레임워크 CLI 가 하는 일이다. 다시 만들면 그것들과
  어긋나고 낡는다.
- 사용자 전역 규칙에 「설정 파일은 작업 대상일 때만 수정한다」가 있어, 도구 체인을 건드리는 스킬은
  그 규칙과 충돌한다.
- `.gitignore` 는 언어마다 내용이 달라 저장소 층을 벗어나고, 이미 `gitignore.io` 와 각 프레임워크
  CLI 가 하는 일이다.

## 결정

git 과 GitHub 에 속하는 것만 다룬다. 언어별 도구 체인은 다루지 않는다. `.gitignore` 전체도 어느
목적도 갖지 않는다.

## 결과

- 검증 방법이 일관된다. 모든 목적을 파일, 훅의 실제 차단, API 응답으로 판정한다.
- 언어별 도구 체인과 `.gitignore` 전체는 범위 밖으로 남는다.
- `.private/` 를 무시하는 `.gitignore` 의 한 줄은 가드의 일부라서 예외다. 그 한 줄의 소유는
  [0003](0003-ownership-of-overlapping-files.md) 이 정한다.
