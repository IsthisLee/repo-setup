# wiki

지금 구현된 기능이 무엇을 하고 어떻게 동작하며 무엇을 바꾸고 어디까지 못 하는지 적는다. 왜 그렇게
만들었는지는 [ADR](../adr/README.md) 에 있고, 세팅 절차는 각 스킬의 `SKILL.md` 에 있다.

기능을 바꾸는 PR 은 그 기능의 페이지를 같은 PR 에서 고친다.

| 페이지 | 다루는 것 |
|---|---|
| [진입점 흐름](setup-flow.md) | `repo-setup` 이 실측하고 고르고 부르고 보고하는 흐름 |
| [개인 정보 가드](privacy.md) | 홈 경로·이메일·사내 식별자가 커밋되는 것을 커밋 시점에 막는다 |
| [라이선스](license.md) | 라이선스를 정하고 `LICENSE` 와 매니페스트가 같은 말을 하게 한다 |
| [테스트 워크플로](ci.md) | 테스트가 푸시마다 돌게 하고 실제로 한 번 돌려 확인한다 |
| [호스트 보안 층](secure.md) | 호스트의 보안 기능을 켜고 액션을 SHA 로 고정한다 |
| [협업 준비](contrib.md) | 기여 안내와 신고처, 서식, 리뷰 담당을 놓고 기본 브랜치를 보호한다 |
| [이 저장소의 개발](development.md) | 이 저장소의 구조, 테스트, 자체 CI, 기여 방법 |

각 페이지의 절은 하는 일, 동작, 바꾸는 것, 한계와 알려진 문제, 관련 파일, 관련 ADR, 확인한 외부 사실
순서다.
