# 기여하기

## 개발 환경

```bash
__SETUP_COMMAND__
```

이 저장소에는 커밋 가드가 걸려 있다. 위 명령을 한 번 돌려야 훅이 켜진다. `--no-verify` 는
가드를 끄는 수단이 아니라 사람이 의도적으로 예외를 만들 때만 쓴다.

## 검사

바꾼 것을 올리기 전에 돌린다.

```bash
__TEST_COMMAND__
```

## 커밋

__COMMIT_CONVENTION__

제목은 `git log --oneline` 에서 혼자 읽혀야 한다. 「버그 수정」처럼 무엇이 바뀌었는지 없는
제목은 쓰지 않는다. 본문에는 무엇을 왜 바꿨는지 적는다.

## 풀 리퀘스트

- 무엇이 필요했고 무엇이 가능해졌는지 먼저 적는다.
- 돌린 명령과 그 출력을 적어 리뷰어가 같은 결과를 볼 수 있게 한다.
- 확인한 것과 확인하지 못한 것을 구분해 적는다.
